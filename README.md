# Product Filter App

A responsive React application that fetches product data from an external API and displays it dynamically in the UI. The app includes filtering functionality based on related items, price range, and ratings, allowing users to refine the displayed results in real time.

## Features

- Fetches product data from a remote API
- Filters items by category, price, and ratings
- Dynamic rendering of filtered results
- Responsive layout for desktop and mobile
- Modular component structure for maintainability

## Tech Stack

- React
- Axios or Fetch API
- CSS
